# 🧑‍💻 User Management React App

This is a simple and responsive user management system built with **React**, **Tailwind CSS**, and the [Reqres API](https://reqres.in/). It supports features like login, user listing with pagination, search with debounce, add new user functionality, and logout.

---

## 🚀 Features

- ✅ Login with validation
- ✅ Protected dashboard route
- ✅ Fetch and display users with pagination
- ✅ Search by name or email (with debounce)
- ✅ Add new user (with optimistic UI update)
- ✅ Logout (clears token and redirects to login)
- ✅ Fully responsive with modern UI

---

## 🧰 Tech Stack

- React 19
- Tailwind CSS
- Vite
- React Router
- Reqres API (Mock backend)
